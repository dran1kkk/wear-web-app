## 📚 Содержание билетов (Высшая математика · ДУ)

| Билет | Теоретическая часть | Практическая часть |
| :---: | :--- | :--- |
| **1** | Определение ДУ 1-го и $n$-го порядка. Задача Коши, ТСЕ. ЛОДУ, характеристическое уравнение, корни, ФСР. | Решение ЛОДУ 2-го порядка (действительные корни, комплексно-сопряжённые корни). |
| **2** | Определения ОР, ЧР, ОИ, ЧИ для 1-го и $n$-го порядков. ЛНДУ, метод вариации постоянных (метод Лагранжа). | Решение уравнения методом Лагранжа. Задача Коши для ДУ 1-го порядка. |
| **3** | Интегральные кривые и изоклины. Поле направлений. ЛНДУ со специальной правой частью (метод подбора). | Резонансные случаи, свободный член. |
| **4** | ДУ с разделяющимися переменными. Однородные ДУ 1-го порядка. Линейная независимость и определитель Вронского. | Задача Коши. Однородное ДУ. |
| **5** | Линейные ДУ 1-го порядка (методы Лагранжа и Бернулли). ЛОДУ высших порядков с постоянными коэффициентами. | Задача Коши. ЛОДУ 4-го порядка с кратными корнями. |
| **6** | Уравнение Бернулли (сведение к линейному, схема решения). Метод подбора частного решения ЛНДУ. | Задача Коши. Резонансный подбор для экспоненты. |
| **7** | ДУ в полных дифференциалах. Признак Эйлера. Восстановление потенциала. Метод вариации постоянных. | Интегрирование. Уравнение. |
| **8** | Уравнения высших порядков, допускающие понижение порядка (Типы I, II, III). Связь нормальных систем с ЛНДУ. | Нормальная система ДУ методом исключения. ДУ. |

## ⚡ Сборка APK через GitHub Actions

Вам не нужно устанавливать Android Studio или настраивать локальный Java/Gradle SDK:

1. Сделайте `push` любых изменений в ветку `main`.
2. Перейдите во вкладку **Actions** в верхней панели репозитория.
3. Откройте последний запуск рабочего процесса **Build Wear OS APK**.
4. В секции **Artifacts** скачайте архив `wear-app-debug`.
5. Извлеките файл `app-debug.apk`.

## 📲 Установка на часы (Sideloading)

### Способ 1: Со смартфона через Bugjaeger / Easy Fire Tools (рекомендуется)

1. **Подготовка часов:**
   * Откройте **Настройки** ➔ **Система** ➔ **Об устройстве** ➔ **Версии**.
   * Нажмите на пункт **Номер сборки** 7 раз, пока не активируется режим разработчика.
   * Вернитесь в **Настройки** ➔ **Для разработчиков**.
   * Включите тумблеры **Отладка по ADB** и **Отладка по Wi-Fi** (или *Беспроводная отладка*).
   * Запомните IP-адрес и порт.

2. **Передача через Bugjaeger:**
   * Убедитесь, что часы и телефон подключены к одной Wi-Fi сети.
   * В приложении **Bugjaeger** нажмите на значок розетки вверху и введите IP:порт часов.
   * Подтвердите запрос на экране часов (*«Всегда разрешать с этого компьютера»*).
   * Перейдите во вкладку **Packages** ➔ нажмите **`+`** ➔ выберите `app-debug.apk`.
   * После уведомления `Success` ярлык **Билеты** появится в меню часов.
