1Определение ДУ 1-го порядка и n-го порядка
1. Дифференциальное уравнение n-го порядка:
Обыкновенным дифференциальным уравнением (ОДУ) n-го порядка называется уравнение, связывающее независимую переменную x, искомую функцию y = f(x) и её производные до n-го порядка включительно: y', y'', ..., y⁽ⁿ⁾.
Общий (неявный) вид:
F(x, y, y', y'', ..., y⁽ⁿ⁾) = 0
Вид, разрешённый относительно старшей производной:
y⁽ⁿ⁾ = f(x, y, y', ..., y⁽ⁿ⁻¹⁾)
2. Порядок дифференциального уравнения:
Порядком ДУ называется порядок наивысшей (старшей) производной, входящей в это уравнение.
3. Дифференциальное уравнение 1-го порядка:
Дифференциальным уравнением первого порядка называется уравнение, связывающее независимую переменную x, искомую функцию y = f(x) и её первую производную y':
Общий (неявный) вид: F(x, y, y') = 0
Вид, разрешённый относительно производной: y' = f(x, y) или dy/dx = f(x, y)
Дифференциальная форма записи: M(x, y) dx + N(x, y) dy = 0
4. Понятие решения ДУ:
Решением ДУ на некотором промежутке называется всякая функция y = φ(x), имеющая непрерывные производные до соответствующего порядка и при подстановке в исходное уравнение превращающая его в тождество.
5. Задача Коши и теорема существования и единственности:
Задача Коши (для 1-го порядка): найти решение y = φ(x) уравнения y' = f(x, y), удовлетворяющее начальному условию y(x₀) = y₀ при x = x₀.
Теорема существования и единственности (для 1-го порядка): если в некоторой области D плоскости xOy, содержащей точку (x₀, y₀), функция f(x, y) и её частная производная ∂f/∂y непрерывны по совокупности аргументов, то существует единственное решение ДУ, удовлетворяющее начальному условию y(x₀) = y₀.
Задача Коши (для n-го порядка): найти решение уравнения y⁽ⁿ⁾ = f(x, y, y', ..., y⁽ⁿ⁻¹⁾), удовлетворяющее n начальным условиям:
y(x₀) = y₀, y'(x₀) = y'₀, ..., y⁽ⁿ⁻¹⁾(x₀) = y₀⁽ⁿ⁻¹⁾
6. Пример из лекции (составление ДУ по семейству решений):
Дано семейство функций: y = C · x² (где C — произвольная постоянная).
Найти ДУ, для которого эта функция является решением:
1) Дифференцируем функцию по x: dy/dx = 2 · C · x
2) Выражаем C из исходной функции: C = y / x²
3) Подставляем C в производную: dy/dx = 2 · (y / x²) · x ⇒ y' = 2y / x
Ответy' = 2y / x
2ЛОДУ. Характеристическое уравнение. Соответствие корням. ФСР и общее решение
1. Определения и свойства ЛОДУ:
ЛОДУ n-го порядка: y⁽ⁿ⁾ + p₁(x) y⁽ⁿ⁻¹⁾ + p₂(x) y⁽ⁿ⁻²⁾ + ... + pₙ(x) y = 0
ЛОДУ 2-го порядка: y'' + p(x) y' + q(x) y = 0
Теорема 1: если y₁(x) и y₂(x) — решения ЛОДУ 2-го порядка, то их сумма y₁(x) + y₂(x) также является решением.
Теорема 2: если y₁(x) — решение ЛОДУ 2-го порядка, то C · y₁(x) (где C = const) также является решением.
Линейная комбинация решений также всегда является решением ЛОДУ.
2. Линейная зависимость, независимость и определитель Вронского:
Решения y₁(x) и y₂(x) ЛОДУ линейно независимы на отрезке [a, b], если: y₁(x) / y₂(x) ≠ const.
В общем случае: α₁ y₁ + ... + αₙ yₙ ≡ 0 выполняется только при α₁ = ... = αₙ = 0.
Определитель Вронского (вронскиан) для двух решений:
W(x) = W(y₁, y₂) = y₁(x) · y'₂(x) - y'₁(x) · y₂(x)
Критерий независимости: частные решения ЛОДУ линейно независимы тогда и только тогда, когда W(x) ≠ 0 на рассматриваемом промежутке.
3. ФСР и структура общего решения ЛОДУ:
ФСР (Фундаментальная система решений): совокупность n линейно независимых частных решений y₁(x), ..., yₙ(x) ЛОДУ n-го порядка.
Общее решение ЛОДУ (ȳ) строится как их линейная комбинация:
ȳ = C₁ · y₁(x) + C₂ · y₂(x) + ... + Cₙ · yₙ(x), где Cᵢ — произвольные постоянные.
4. Характеристическое уравнение ЛОДУ с постоянными коэффициентами:
Для уравнения y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = 0 решения ищутся в виде y = e^(λx).
Подстановка приводит к характеристическому уравнению:
λⁿ + a₁ λⁿ⁻¹ + ... + aₙ₋₁ λ + aₙ = 0
Правило соответствия замен: y⁽ⁿ⁾ → λⁿ, ..., y'' → λ², y' → λ, y → 1.
Действительный простой корень λ = λ₀
Кратность
k = 1
Соответствующие решения в составе ФСР
y = e^(λ₀ · x)
Действительный кратный корень λ = λ₀
Кратность
кратность r > 1
Соответствующие решения в составе ФСР
y₁ = e^(λ₀·x), y₂ = x·e^(λ₀·x), ..., yᵣ = xʳ⁻¹·e^(λ₀·x)
Пара простых комплексно-сопряжённых корней λ = α ± iβ
Кратность
k = 1
Соответствующие решения в составе ФСР
y₁ = e^(αx) · cos(βx) y₂ = e^(αx) · sin(βx)
Пара кратных комплексно-сопряжённых корней λ = α ± iβ
Кратность
кратность r > 1
Соответствующие решения в составе ФСР
y₁ = e^(αx) cos(βx), y₂ = e^(αx) sin(βx) y₃ = x e^(αx) cos(βx), y₄ = x e^(αx) sin(βx) ... y₂ᵣ₋₁ = xʳ⁻¹ e^(αx) cos(βx), y₂ᵣ = xʳ⁻¹ e^(αx) sin(βx)
3Решить дифференциальное уравнение
Вариант 1: y'' + 2y' - 3y = 0
1) Составляем характеристическое уравнение: λ² + 2λ - 3 = 0
2) Находим корни по теореме Виета:
λ₁ + λ₂ = -2, λ₁ · λ₂ = -3 ⇒ λ₁ = -3, λ₂ = 1 (корни действительные, различные)
3) ФСР: y₁ = e^(-3x), y₂ = e^x
4) Общее решение ЛОДУ (ОР ЛОДУ):
ȳ = C₁ · e^(-3x) + C₂ · e^x, где C₁, C₂ — произвольные постоянные.
Вариант 2: y'' + 2y' + 7y = 0
1) Составляем характеристическое уравнение: λ² + 2λ + 7 = 0
2) Вычисляем дискриминант и корни:
D = 2² - 4 · 1 · 7 = 4 - 28 = -24 < 0
√D = ± 2i√6
λ₁,₂ = (-2 ± 2i√6) / 2 = -1 ± i√6 ⇒ α = -1, β = √6
3) ФСР: y₁ = e^(-x) · cos(√6 · x), y₂ = e^(-x) · sin(√6 · x)
4) Общее решение ЛОДУ:
ȳ = C₁ · e^(-x) cos(√6 · x) + C₂ · e^(-x) sin(√6 · x) = e^(-x) · (C₁ cos(√6 · x) + C₂ sin(√6 · x)),
где C₁, C₂ — произвольные постоянные.
Вариант 3: y'' + 2y' + 3y = 0
1) Составляем характеристическое уравнение: λ² + 2λ + 3 = 0
2) Находим корни:
D = 4 - 12 = -8 < 0
λ₁,₂ = (-2 ± 2i√2) / 2 = -1 ± i√2 ⇒ α = -1, β = √2
3) ФСР: y₁ = e^(-x) · cos(√2 · x), y₂ = e^(-x) · sin(√2 · x)
4) Общее решение ЛОДУ:
ȳ = e^(-x) · (C₁ cos(√2 · x) + C₂ sin(√2 · x)),
где C₁, C₂ — произвольные постоянные.

1Определение ОР, ЧР, ОИ, ЧИ дифференциального уравнения
1. Для дифференциальных уравнений первого порядка:
Общее решение (ОР):
Функция y = φ(x, C), зависящая от одной произвольной постоянной C, называется общим решением ДУ 1-го порядка, если:
1) Она обращает ДУ в тождество при любом допустимом значении C.
2) Для любого допустимого начального условия y(x₀) = y₀ (из области существования и единственности задачи Коши) существует единственное значение C = C₀ такое, что y₀ = φ(x₀, C₀).
Частное решение (ЧР):
Всякая функция y = φ(x, C₀), получаемая из общего решения при конкретном числовом значении постоянной C = C₀, найденном из начальных условий (задачи Коши).
Общий интеграл (ОИ):
Соотношение вида Φ(x, y, C) = 0, не разрешённое относительно y (заданное в неявной форме), которое неявно определяет общее решение ДУ.
Частный интеграл (ЧИ):
Соотношение Φ(x, y, C₀) = 0, полученное из общего интеграла при конкретном фиксированном значении C = C₀.
2. Для дифференциальных уравнений n-го порядка:
Общее решение (ОР):
Функция y = φ(x, C₁, C₂, ..., Cₙ), зависящая от n независимых произвольных постоянных, называется общим решением ДУ n-го порядка, если:
1) Она удовлетворяет ДУ при любых допустимых значениях C₁, ..., Cₙ.
2) Для любой задачи Коши с начальными условиями y(x₀) = y₀, y'(x₀) = y'₀, ..., y⁽ⁿ⁻¹⁾(x₀) = y₀⁽ⁿ⁻¹⁾ система уравнений относительно C₁, ..., Cₙ имеет единственное решение C₁ = C₁⁰, ..., Cₙ = Cₙ⁰.
Частное решение (ЧР):
Решение y = φ(x, C₁⁰, C₂⁰, ..., Cₙ⁰), полученное из общего решения при конкретных числовых значениях констант, найденных из начальных условий.
Общий и частный интегралы:
Неявное соотношение Φ(x, y, C₁, ..., Cₙ) = 0 называется общим интегралом ДУ n-го порядка; соотношение при фиксированных константах Φ(x, y, C₁⁰, ..., Cₙ⁰) = 0 — частным интегралом.
2ЛНДУ. Метод вариации произвольных постоянных (метод Лагранжа)
1. Вид ЛНДУ и структура общего решения:
Линейное неоднородное дифференциальное уравнение (ЛНДУ) n-го порядка имеет вид:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = f(x), где f(x) ≠ 0.
Для 2-го порядка:
y'' + a₁ y' + a₂ y = f(x)
Теорема о структуре общего решения ЛНДУ: общее решение неоднородного уравнения y складывается из общего решения ȳ соответствующего однородного уравнения (ЛОДУ) и частного решения ỹ неоднородного уравнения:
y = ȳ + ỹ
2. Алгоритм метода вариации для ЛНДУ 2-го порядка (метод Лагранжа):
1) Находим общее решение соответствующего ЛОДУ (y'' + a₁ y' + a₂ y = 0):
ȳ = C₁ · y₁(x) + C₂ · y₂(x), где y₁, y₂ — ФСР.
2) Ищем общее решение ЛНДУ в том же виде, варьируя постоянные (считая их функциями от x):
y = C₁(x) · y₁(x) + C₂(x) · y₂(x)
3) Дифференцируем y(x):
y' = C'₁(x) y₁ + C'₂(x) y₂ + C₁(x) y'₁ + C₂(x) y'₂
Накладываем условие Лагранжа: C'₁(x) y₁(x) + C'₂(x) y₂(x) = 0
Тогда первая производная имеет вид: y' = C₁(x) y'₁(x) + C₂(x) y'₂(x)
4) Находим вторую производную и подставляем y, y', y'' в исходное ЛНДУ. В результате группировки получаем систему уравнений относительно производных C'₁(x) и C'₂(x):
{ C'₁(x) · y₁(x) + C'₂(x) · y₂(x) = 0
{ C'₁(x) · y'₁(x) + C'₂(x) · y'₂(x) = f(x)
5) Главный определитель системы — это определитель Вронского ФСР:
W(x) = y₁ y'₂ - y'₁ y₂ ≠ 0
По формулам Крамера находим производные:
C'₁(x) = - (y₂(x) · f(x)) / W(x)
C'₂(x) = (y₁(x) · f(x)) / W(x)
6) Интегрируем полученные выражения:
C₁(x) = - ∫ (y₂(x) · f(x) / W(x)) dx + C̄₁
C₂(x) = ∫ (y₁(x) · f(x) / W(x)) dx + C̄₂
где C̄₁, C̄₂ — числовые произвольные постоянные.
7) Подставляем найденные функции C₁(x) и C₂(x) в формулу общего решения y = C₁(x) y₁ + C₂(x) y₂.
3Решить дифференциальное уравнение
Задача: Найти общее решение ЛНДУ методом вариации постоянных:
y'' + y = 1 / cos(x)
1) Находим общее решение соответствующего ЛОДУ: y'' + y = 0
Характеристическое уравнение: λ² + 1 = 0 ⇒ λ₁,₂ = ± i (α = 0, β = 1)
ФСР: y₁(x) = cos(x), y₂(x) = sin(x)
ОР ЛОДУ: ȳ = C₁ · cos(x) + C₂ · sin(x)
2) Вычисляем определитель Вронского:
W(x) = | cos(x) sin(x) |
| -sin(x) cos(x) | = cos²(x) - (-sin²(x)) = cos²(x) + sin²(x) = 1 ≠ 0
3) Составляем систему для нахождения C'₁(x) и C'₂(x):
{ C'₁(x) · cos(x) + C'₂(x) · sin(x) = 0
{ -C'₁(x) · sin(x) + C'₂(x) · cos(x) = 1 / cos(x)
4) Находим производные по формулам Крамера:
C'₁(x) = - (sin(x) · (1 / cos(x))) / 1 = - tg(x)
C'₂(x) = (cos(x) · (1 / cos(x))) / 1 = 1
5) Интегрируем производные:
C₁(x) = - ∫ tg(x) dx = - ∫ (sin(x) / cos(x)) dx = ∫ (d(cos(x)) / cos(x)) = ln|cos(x)| + C₁
C₂(x) = ∫ 1 dx = x + C₂
6) Записываем общее решение ЛНДУ:
y = (ln|cos(x)| + C₁) · cos(x) + (x + C₂) · sin(x)
или в окончательном виде:
y = C₁ · cos(x) + C₂ · sin(x) + cos(x) · ln|cos(x)| + x · sin(x)
Ответy = C₁ · cos(x) + C₂ · sin(x) + cos(x) · ln|cos(x)| + x · sin(x)
Дополнительный пример из лекций (ЛНДУ 1-го порядка методом вариации / методом Лагранжа):
Задача: решить задачу Коши y' + tg(x) · y = 1 / cos(x), y(0) = 1
1) Запишем соответствующее однородное ДУ: y' + tg(x) · y = 0
dy/y = -tg(x) dx ⇒ ln|y| = ln|cos(x)| + ln|C| ⇒ ȳ = C · cos(x)
2) Находим ОР неоднородного ДУ в виде: y = C(x) · cos(x)
y' = C'(x) · cos(x) - C(x) · sin(x)
3) Подставляем в исходное уравнение:
C'(x) · cos(x) - C(x) · sin(x) + tg(x) · C(x) · cos(x) = 1 / cos(x)
C'(x) · cos(x) = 1 / cos(x) ⇒ C'(x) = 1 / cos²(x)
4) Интегрируем: C(x) = ∫ (dx / cos²(x)) = tg(x) + C
5) Общее решение: y = (tg(x) + C) · cos(x) = sin(x) + C · cos(x)
6) Находим C из начального условия y(0) = 1:
1 = sin(0) + C · cos(0) ⇒ 1 = 0 + C · 1 ⇒ C = 1
Частное решение: y = sin(x) + cos(x)
Ответy = sin(x) + cos(x)

1Интегральные кривые и изоклины
1. Интегральные кривые:
Геометрический смысл ДУ 1-го порядка y' = f(x, y):
Уравнение y' = f(x, y) в каждой точке (x, y) плоскости задаёт угловой коэффициент касательной k = tg(α) = y' = f(x, y). Совокупность этих направлений образует поле направлений дифференциального уравнения.
Интегральная кривая — это график любого частного решения y = φ(x) дифференциального уравнения в плоскости xOy. В каждой своей точке интегральная кривая касается соответствующего направления поля.
Семейство интегральных кривых — это геометрическое представление общего решения y = φ(x, C) или общего интеграла Φ(x, y, C) = 0. Через каждую точку области существования и единственности проходит ровно одна интегральная кривая семейства.
Пример из лекций: для уравнения y' = 2x + 2 общее решение y = x² + 2x + C представляет собой семейство конгруэнтных парабол, смещённых вдоль оси Oy.
2. Изоклины:
Определение изоклины:
Изоклиной называется геометрическое место точек плоскости xOy, в которых касательные к интегральным кривым имеют одинаковое направление (один и тот же наклон / угловой коэффициент k = const).
Уравнение изоклины:
Для уравнения y' = f(x, y) уравнение изоклины имеет вид:
f(x, y) = k, где k = const (параметр наклона).
Применение метода изоклин (качественное интегрирование):
1) Задают серию фиксированных значений наклона k (например, k = -2, -1, 0, 1, 2).
2) Строят соответствующие линии изоклин f(x, y) = k.
3) На каждой изоклине наносят короткие отрезки-штрихи с постоянным угловым коэффициентом k (tg(α) = k).
В частности, изоклина f(x, y) = 0 даёт геометрическое место точек с горизонтальными касательными (возможные экстремумы интегральных кривых). ✎ поправлено
4) По полученному полю штрихов приближённо вычерчивают форму интегральных кривых без аналитического интегрирования ДУ.
2ЛНДУ. Метод подбора частного решения (метод неопределённых коэффициентов)
1. Общий вид уравнения и структура решения:
Рассматривается ЛНДУ с постоянными действительными коэффициентами:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = f(x)
Для уравнения 2-го порядка:
y'' + a₁ y' + a₂ y = f(x)
Общее решение ЛНДУ строится по формуле: y = ȳ + ỹ, где:
ȳ — общее решение соответствующего однородного уравнения (ЛОДУ), найденное через корни характеристического уравнения λⁿ + a₁ λⁿ⁻¹ + ... + aₙ = 0;
ỹ — частное решение ЛНДУ, подбираемое по специальному виду правой части f(x).
2. Специальный вид правой части (квазимногочлен):
Метод подбора применим, если правая часть f(x) имеет специальный вид:
f(x) = e^(αx) · [ Pₙ(x) · cos(βx) + Qₘ(x) · sin(βx) ]
где Pₙ(x) и Qₘ(x) — многочлены от x степеней n и m соответственно.
Параметрами правой части являются: контрольное число γ = α ± iβ и степень l = max{n, m}.
3. Структура подбора частного решения ỹ:
Частное решение ищется в виде:
ỹ = xʳ · e^(αx) · [ P̃_l(x) · cos(βx) + Q̃_l(x) · sin(βx) ]
где:
α и β берутся непосредственно из правой части f(x);
l = max{deg(P), deg(Q)} — наивысшая степень многочленов в правой части;
P̃_l(x) и Q̃_l(x) — полные многочлены степени l с неопределёнными коэффициентами;
r — показатель резонанса (кратность совпадения контрольного числа γ = α + iβ с корнями характеристического уравнения ЛОДУ):
- если число (α + iβ) НЕ является корнем характеристического уравнения, то r = 0 (резонанса нет);
- если число (α + iβ) является корнем характеристического уравнения кратности k, то r = k (резонансный случай).
f(x) = Pₘ(x) (многочлен степени m)
Контрольное число и резонанс
α = 0, β = 0 ⇒ γ = 0
r = 0, если λ = 0 не корень
r = k, если λ = 0 корень кратности k
Форма подбора частного решения ỹ
ỹ = xʳ · (A_m xᵐ + ... + A₁ x + A₀)
f(x) = e^(αx) · Pₘ(x)
Контрольное число и резонанс
β = 0 ⇒ γ = α
r = 0, если λ = α не корень
r = k, если λ = α корень кратности k
Форма подбора частного решения ỹ
ỹ = xʳ · e^(αx) · (A_m xᵐ + ... + A₀)
f(x) = Pₙ(x) cos(βx) + Qₘ(x) sin(βx)
Контрольное число и резонанс
α = 0 ⇒ γ = ±iβ, l = max{n, m}
r = 0, если ±iβ не корни
r = 1, если ±iβ корни ЛОДУ
Форма подбора частного решения ỹ
ỹ = xʳ · [ P̃_l(x) cos(βx) + Q̃_l(x) sin(βx) ]
f(x) = e^(αx) [ Pₙ(x) cos(βx) + Qₘ(x) sin(βx) ]
Контрольное число и резонанс
γ = α ± iβ, l = max{n, m}
r = 0, если α ± iβ не корни
r = k, если α ± iβ корни кратности k
Форма подбора частного решения ỹ
ỹ = xʳ e^(αx) [ P̃_l(x) cos(βx) + Q̃_l(x) sin(βx) ]
4. Алгоритм нахождения коэффициентов:
1) Вычисляют производные ỹ', ỹ'', ..., ỹ⁽ⁿ⁾.
2) Подставляют ỹ и её производные в исходное ЛНДУ.
3) Приравнивают коэффициенты при одинаковых базисных функциях (степенях x, cos(βx), sin(βx)) в левой и правой частях.
4) Решают полученную линейную систему и находят числовые значения неизвестных коэффициентов.

Пример 1 (из конспекта лекций — резонансный случай экспоненты):
Задача: решить ЛНДУ y'' - y = e^x
1) Решаем соответствующее ЛОДУ: y'' - y = 0
Характеристическое уравнение: λ² - 1 = 0 ⇒ (λ - 1)(λ + 1) = 0
Корни: λ₁ = 1, λ₂ = -1 (действительные простые, k = 1)
ФСР: y₁ = e^x, y₂ = e^(-x)
ОР ЛОДУ: ȳ = C₁ · e^x + C₂ · e^(-x)
2) Анализируем правую часть: f(x) = e^x
α = 1, β = 0 ⇒ контрольное число γ = α + iβ = 1.
Число γ = 1 совпадает с корнем характеристического уравнения λ₁ = 1 кратности k = 1 ⇒ показатель резонанса r = 1.
Степень многочлена: l = 0 ⇒ многочлен нулевой степени P₀(x) = A (константа).
Вид частного решения: ỹ = x¹ · e^(1·x) · A = A · x · e^x
3) Находим неопределённый коэффициент A:
Дифференцируем ỹ:
ỹ' = A · (e^x + x · e^x) = A · e^x · (1 + x)
ỹ'' = A · (e^x · (1 + x) + e^x · 1) = A · e^x · (2 + x)
Подставляем ỹ и ỹ'' в исходное уравнение y'' - y = e^x:
A · e^x · (2 + x) - A · x · e^x = e^x
A · e^x · (2 + x - x) = e^x
2A · e^x = e^x ⇒ 2A = 1 ⇒ A = 1/2
Следовательно, частное решение: ỹ = (1/2) · x · e^x
4) Записываем общее решение ЛНДУ: y = ȳ + ỹ
y = C₁ · e^x + C₂ · e^(-x) + (1/2) · x · e^x
Ответy = C₁ · e^x + C₂ · e^(-x) + (1/2) · x · e^x

1ДУ с разделяющимися переменными и однородные ДУ 1-го порядка (вид, определение, схема решения)
ЧАСТЬ 1. Дифференциальные уравнения с разделяющимися переменными
1. Вид и определение:
Дифференциальным уравнением с разделяющимися переменными называется уравнение 1-го порядка вида:
M₁(x) · N₁(y) dx + M₂(x) · N₂(y) dy = 0
или в форме, разрешённой относительно производной:
y' = f₁(x) · f₂(y)
Главная особенность: коэффициенты при дифференциалах dx и dy распадаются на множители, каждый из которых зависит только от одной переменной (только от x или только от y).
2. Схема и алгоритм решения:
Шаг 1 (Разделение переменных): делим обе части уравнения на произведение N₁(y) · M₂(x) ≠ 0:
[M₁(x) / M₂(x)] dx + [N₂(y) / N₁(y)] dy = 0
В результате при dx стоит функция только от x, а при dy — только от y.
Шаг 2 (Интегрирование): интегрируем обе части полученного равенства:
∫ [M₁(x) / M₂(x)] dx + ∫ [N₂(y) / N₁(y)] dy = C
В результате получаем общий интеграл уравнения Φ(x, y, C) = 0. Если возможно, выражаем y через x, получая общее решение y = φ(x, C).
Шаг 3 (Проверка особых решений): деление на N₁(y) · M₂(x) законно лишь при условии, что этот множитель не равен нулю. Приравнивая N₁(y) = 0 и M₂(x) = 0, находим постоянные решения. Если они не получаются из общего интеграла ни при каком значении C, то они являются особыми решениями и должны быть включены в итоговый ответ.
ЧАСТЬ 2. Однородные дифференциальные уравнения 1-го порядка
1. Определение однородной функции:
Функция f(x, y) называется однородной функцией m-го измерения (степени m), если при одновременном масштабировании аргументов в λ раз справедливо тождество:
f(λx, λy) = λᵐ · f(x, y)
Пример: M(x, y) = x² + y² + xy ⇒ M(λx, λy) = (λx)² + (λy)² + (λx)(λy) = λ²(x² + y² + xy) = λ² · M(x, y) ⇒ степень m = 2.
2. Определение и вид однородного ДУ:
Уравнение M(x, y) dx + N(x, y) dy = 0 называется однородным, если M(x, y) и N(x, y) — однородные функции одинакового измерения m.
Любое однородное ДУ 1-го порядка может быть приведено к каноническому виду, разрешённому относительно производной:
y' = f(y / x)
3. Схема и алгоритм решения:
Шаг 1 (Замена переменной): вводится новая неизвестная функция t = t(x):
y / x = t ⇒ y = t · x
Шаг 2 (Выражение производной): дифференцируем по правилу произведения:
y' = t' · x + t (или в дифференциалах: dy = t dx + x dt)
Шаг 3 (Сведение к уравнению с разделяющимися переменными):
t + t' · x = f(t) ⇒ x · (dt / dx) = f(t) - t ⇒ dt / (f(t) - t) = dx / x
Шаг 4 (Интегрирование): интегрируем обе части равенства:
∫ dt / (f(t) - t) = ∫ dx / x + C
Шаг 5 (Обратная замена): подставляем t = y / x и получаем общий интеграл или общее решение исходного ДУ.
2Линейная зависимость и независимость решений ЛОДУ. Определитель Вронского при решении ЛОДУ
1. Линейная зависимость и линейная независимость функций и решений:
Рассматривается ЛОДУ 2-го порядка: y'' + p(x) y' + q(x) y = 0 на промежутке (a, b).
Определение 1 (Линейная независимость): два решения y₁(x) и y₂(x) называются линейно независимыми на промежутке (a, b), если их отношение не является постоянным числом:
y₁(x) / y₂(x) ≠ const
Строгое алгебраическое определение: равенство α₁ y₁(x) + α₂ y₂(x) ≡ 0 выполняется тогда и только тогда, когда α₁ = α₂ = 0.
Определение 2 (Линейная зависимость): два решения y₁(x) и y₂(x) называются линейно зависимыми, если существуют такие числа α₁ и α₂, не равные нулю одновременно (α₁² + α₂² ≠ 0), что:
α₁ y₁(x) + α₂ y₂(x) ≡ 0 ⇔ y₁(x) / y₂(x) = const = c
Обобщение на n решений: система {y₁(x), y₂(x), ..., yₙ(x)} линейно независима, если линейная комбинация
α₁ y₁(x) + α₂ y₂(x) + ... + αₙ yₙ(x) ≡ 0 выполняется исключительно при α₁ = α₂ = ... = αₙ = 0.
2. Определитель Вронского (вронскиан):
Для двух дифференцируемых функций y₁(x) и y₂(x) определитель Вронского имеет вид:
W(x) = W(y₁, y₂) = | y₁(x) y₂(x) |
| y'₁(x) y'₂(x) | = y₁(x) · y'₂(x) - y'₁(x) · y₂(x)
Для n функций y₁(x), y₂(x), ..., yₙ(x):
W(x) = | y₁ y₂ ... yₙ |
| y'₁ y'₂ ... y'ₙ |
| ... ... ... ... |
| y₁⁽ⁿ⁻¹⁾ y₂⁽ⁿ⁻¹⁾ ... yₙ⁽ⁿ⁻¹⁾ |
3. Роль и свойства определителя Вронского при решении ЛОДУ:
Теорема 1 (Необходимое условие линейной зависимости): если решения y₁(x), y₂(x) ЛОДУ линейно зависимы на промежутке (a, b), то определитель Вронского тождественно равен нулю: W(x) ≡ 0.
Теорема 2 (Критерий линейной независимости): если функции y₁(x) и y₂(x) являются решениями ЛОДУ, то они линейно независимы тогда и только тогда, когда определитель Вронского W(x) не равен нулю ни в одной точке интервала (a, b): ✎ поправлено
W(x) ≠ 0 (для всех x ∈ (a, b))
Если же в какой-либо одной точке x₀ значение W(x₀) = 0, то в силу формулы Остроградского-Лиувилля W(x) ≡ 0 везде.
Связь с фундаментальной системой решений (ФСР):
Система решений {y₁, y₂, ..., yₙ} образует ФСР тогда и только тогда, когда W(y₁, ..., yₙ) ≠ 0. Только в этом случае общее решение ЛОДУ выражается формулой:
ȳ = C₁ y₁ + C₂ y₂ + ... + Cₙ yₙ
Восстановление ЛОДУ 2-го порядка по его ФСР через определитель Вронского (из лекций):
Если задана ФСР {y₁, y₂}, то уравнение восстанавливается через определитель 3-го порядка:
| y y₁ y₂ |
| y' y'₁ y'₂ | = 0
| y'' y''₁ y''₂|
Пример из лекций: для y₁ = e^x, y₂ = e^(-x) вычисление даёт -2(y'' - y) = 0 ⇒ y'' - y = 0.

(1 + x²) dy = -y dx

∫ (dy / y) = - ∫ (dx / (1 + x²))

M(x, y) = y² + xy ⇒ M(λx, λy) = λ²y² + λ²xy = λ² · M(x, y) (степень 2)
N(x, y) = -x² ⇒ N(λx, λy) = -(λx)² = λ² · N(x, y) (степень 2)
Функции M и N однородные 2-го измерения ⇒ ДУ однородное.

x² dy = (y² + xy) dx ⇒ dy/dx = (y² + xy) / x² ⇒ y' = (y/x)² + (y/x)

Пусть t = y / x ⇒ y = t · x ⇒ y' = t + t' · x
Подставляем в уравнение:
t + t' · x = t² + t
t' · x = t²
(dt / dx) · x = t²

dt / t² = dx / x (при t ≠ 0, x ≠ 0)
∫ (dt / t²) = ∫ (dx / x)
- 1 / t = ln|x| + ln|C| = ln|C · x|

- 1 / (y / x) = ln|C · x|
- x / y = ln|C · x| — общий интеграл уравнения.

(а также потерянное при делении решение t = 0 ⇒ y = 0).

1Однородные ДУ 1-го порядка. Линейные ДУ 1-го порядка (метод Лагранжа и метод Бернулли)
ЧАСТЬ 1. Однородные дифференциальные уравнения 1-го порядка
1. Определение однородной функции:
Функция f(x, y) называется однородной функцией степени (измерения) m, если при одновременном масштабировании аргументов в λ раз выполняется тождество: f(λx, λy) = λᵐ · f(x, y).
2. Определение и канонический вид однородного ДУ:
Уравнение M(x, y) dx + N(x, y) dy = 0 называется однородным, если M(x, y) и N(x, y) — однородные функции одной и той же степени m.
Любое однородное ДУ 1-го порядка приводится к виду, разрешённому относительно производной:
y' = f(y / x)
3. Схема интегрирования:
Замена переменной: y / x = t ⇒ y = t · x ⇒ y' = t + t' · x
Подстановка приводит к уравнению с разделяющимися переменными:
t + t' · x = f(t) ⇒ x · (dt / dx) = f(t) - t ⇒ dt / (f(t) - t) = dx / x
Интегрируем обе части и выполняем обратную замену t = y / x.
ЧАСТЬ 2. Линейные дифференциальные уравнения 1-го порядка
1. Определение и канонический вид:
Линейным дифференциальным уравнением 1-го порядка называется уравнение, линейное относительно искомой функции y и её производной y':
y' + P(x) · y = Q(x)
где P(x) и Q(x) — непрерывные функции аргумента x на некотором интервале.
Если Q(x) ≡ 0, уравнение называется линейным однородным (ЛОДУ 1-го порядка): y' + P(x) · y = 0.
Если Q(x) ≠ 0, уравнение называется линейным неоднородным (ЛНДУ 1-го порядка).
2. Структура общего решения:
Общее решение ЛНДУ 1-го порядка складывается из общего решения соответствующего однородного уравнения ȳ и частного решения неоднородного уравнения ỹ:
y = ȳ + ỹ
3. Способ 1: Метод вариации произвольной постоянной (метод Лагранжа):
Шаг 1: Записываем соответствующее однородное уравнение: y' + P(x) · y = 0.
Разделяем переменные и интегрируем:
dy / y = - P(x) dx ⇒ ln|y| = - ∫ P(x) dx + ln|C| ⇒ ȳ = C · e^(- ∫ P(x) dx)
Шаг 2: Ищем общее решение исходного неоднородного уравнения в том же виде, полагая константу C неизвестной функцией C(x):
y = C(x) · e^(- ∫ P(x) dx)
Шаг 3: Находим производную y' по правилу произведения:
y' = C'(x) · e^(- ∫ P(x) dx) - C(x) · P(x) · e^(- ∫ P(x) dx)
Шаг 4: Подставляем y и y' в исходное уравнение y' + P(x) · y = Q(x):
C'(x) · e^(- ∫ P(x) dx) - C(x) · P(x) · e^(- ∫ P(x) dx) + P(x) · C(x) · e^(- ∫ P(x) dx) = Q(x)
Слагаемые с C(x) взаимно уничтожаются, остаётся:
C'(x) · e^(- ∫ P(x) dx) = Q(x) ⇒ C'(x) = Q(x) · e^(∫ P(x) dx)
Шаг 5: Интегрируем производную C'(x):
C(x) = ∫ Q(x) · e^(∫ P(x) dx) dx + C̄, где C̄ — числовая произвольная постоянная.
Шаг 6: Записываем общее решение ЛНДУ 1-го порядка:
y = e^(- ∫ P(x) dx) · [ ∫ Q(x) · e^(∫ P(x) dx) dx + C̄ ]
4. Способ 2: Метод Бернулли (подстановка y = u · v):
Шаг 1: Ищем решение в виде произведения двух неизвестных функций от x:
y = u(x) · v(x) ⇒ y' = u' · v + u · v'
Шаг 2: Подставляем в уравнение y' + P(x) · y = Q(x):
u' · v + u · v' + P(x) · u · v = Q(x)
Группируем слагаемые с множителем u:
u' · v + u · [ v' + P(x) · v ] = Q(x)
Шаг 3: Поскольку одна из функций (например, v) может быть выбрана произвольно, потребуем, чтобы выражение в скобках обратилось в ноль. Получаем совместную систему двух уравнений:
1) v' + P(x) · v = 0
2) u' · v = Q(x)
Шаг 4: Находим функцию v(x) из 1-го уравнения с разделяющимися переменными:
dv / dx = - P(x) · v ⇒ dv / v = - P(x) dx ⇒ ln|v| = - ∫ P(x) dx ⇒ v(x) = e^(- ∫ P(x) dx)
(произвольную постоянную здесь полагают равной 0, фиксируя одно ненулевое частное решение v(x)).
Шаг 5: Подставляем найденную v(x) во 2-е уравнение системы и находим u(x):
u' · e^(- ∫ P(x) dx) = Q(x) ⇒ du / dx = Q(x) / v(x) = Q(x) · e^(∫ P(x) dx)
u(x) = ∫ [ Q(x) / v(x) ] dx + C = ∫ Q(x) · e^(∫ P(x) dx) dx + C
Шаг 6: Записываем общее решение:
y = u(x) · v(x) = [ ∫ Q(x) · e^(∫ P(x) dx) dx + C ] · e^(- ∫ P(x) dx)
2ЛОДУ высших порядков, характеристическое уравнение, ФСР и структура общего решения
1. Канонический вид ЛОДУ n-го порядка с постоянными коэффициентами:
Уравнение имеет вид:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + a₂ y⁽ⁿ⁻²⁾ + ... + aₙ₋₁ y' + aₙ y = 0, где aᵢ ∈ ℝ — постоянные коэффициенты.
2. Характеристическое уравнение (метод Эйлера):
Ищем нетривиальное решение в виде показательной функции y = e^(λx). Так как y⁽ᵏ⁾ = λᵏ · e^(λx), после подстановки и сокращения на e^(λx) ≠ 0 получаем характеристическое уравнение:
λⁿ + a₁ λⁿ⁻¹ + a₂ λⁿ⁻² + ... + aₙ₋₁ λ + aₙ = 0
Правило составления: производная порядка k заменяется на λᵏ (y⁽ⁿ⁾ → λⁿ, y'' → λ², y' → λ, y → 1).
3. Фундаментальная система решений (ФСР) и структура общего решения:
ФСР ЛОДУ n-го порядка — это совокупность n линейно независимых частных решений y₁(x), y₂(x), ..., yₙ(x), для которых определитель Вронского W(x) ≠ 0.
Теорема об общем решении: общее решение ЛОДУ n-го порядка выражается как линейная комбинация функций ФСР:
ȳ = C₁ · y₁(x) + C₂ · y₂(x) + ... + Cₙ · yₙ(x), где C₁, ..., Cₙ — произвольные постоянные.
Правила построения ФСР по корням характеристического уравнения:
Каждому действительному простому корню λ = λ₀ соответствует одно решение: y = e^(λ₀ · x).
Каждому действительному корню λ = λ₀ кратности r соответствует r решений:
y₁ = e^(λ₀·x), y₂ = x · e^(λ₀·x), ..., yᵣ = xʳ⁻¹ · e^(λ₀·x).
Каждой паре простых комплексно-сопряжённых корней λ = α ± iβ (кратность 1) соответствуют 2 действительных решения:
y₁ = e^(αx) · cos(βx), y₂ = e^(αx) · sin(βx).
Каждой паре комплексно-сопряжённых корней λ = α ± iβ кратности r соответствуют 2r действительных решений:
e^(αx) cos(βx), e^(αx) sin(βx), x e^(αx) cos(βx), x e^(αx) sin(βx), ..., xʳ⁻¹ e^(αx) cos(βx), xʳ⁻¹ e^(αx) sin(βx).

1Дифференциальное уравнение Бернулли (вид, сведение к линейному, схема решения)
1. Определение и канонический вид уравнения Бернулли:
Дифференциальным уравнением Бернулли называется нелинейное уравнение 1-го порядка вида:
y' + P(x) · y = Q(x) · yᵐ
где P(x) и Q(x) — непрерывные функции аргумента x, а m — действительное число (m ≠ 0 и m ≠ 1).
Замечание о частных случаях показателя степени m:
При m = 0 уравнение превращается в линейное неоднородное ДУ 1-го порядка: y' + P(x)y = Q(x);
При m = 1 уравнение становится уравнением с разделяющимися переменными: y' + [P(x) - Q(x)]y = 0.
Поэтому предполагается, что m ≠ 0 и m ≠ 1.
2. Сведение к линейному уравнению с помощью замены (классический метод):
Шаг 1: Делим обе части уравнения на yᵐ (предполагая y ≠ 0):
y^(-m) · y' + P(x) · y^(1-m) = Q(x)
Шаг 2: Вводим новую неизвестную функцию z = z(x) подстановкой:
z = y^(1-m)
Шаг 3: Находим производную функции z по x:
z' = (1 - m) · y^(-m) · y' ⇒ y^(-m) · y' = z' / (1 - m)
Шаг 4: Подставляем z и y^(-m) · y' в преобразованное уравнение:
z' / (1 - m) + P(x) · z = Q(x)
Умножая обе части на (1 - m), получаем линейное неоднородное ДУ 1-го порядка относительно z(x):
z' + (1 - m) P(x) · z = (1 - m) Q(x)
Шаг 5: Решаем полученное линейное уравнение относительно z(x) методом Бернулли (z = u · v) или методом Лагранжа.
Шаг 6: Выполняем обратную замену y = z^(1 / (1 - m)) и получаем общее решение исходного уравнения Бернулли.
(При m > 0 решение y = 0 является решением уравнения, которое проверяется отдельно).
3. Прямой метод Бернулли (подстановка y = u · v):
Уравнение Бернулли можно решать напрямую, не сводя к z, с помощью подстановки y = u · v:
1) Полагаем y = u(x) · v(x) ⇒ y' = u'v + uv'
2) Подставляем в исходное уравнение: u'v + uv' + P(x) u v = Q(x) · uᵐ vᵐ
3) Группируем слагаемые с множителем u: u'v + u · [ v' + P(x) v ] = Q(x) · uᵐ vᵐ
4) Требуем, чтобы v' + P(x) v = 0. Находим частное ненулевое решение v(x) разделением переменных:
v(x) = e^(- ∫ P(x) dx)
5) Подставляем найденную v(x) во второе уравнение: u' · v(x) = Q(x) · uᵐ · [v(x)]ᵐ ⇒ u' / uᵐ = Q(x) · [v(x)]ᵐ⁻¹
Это уравнение с разделяющимися переменными относительно u(x), интегрируя которое находим u(x).
6) Окончательно находим y = u(x) · v(x).

Следовательно: ỹ = (1/2) · x · e^x
4) Записываем общее решение ЛНДУ:
y = ȳ + ỹ = C₁ · e^x + C₂ · e^(-x) + (1/2) · x · e^x
Ответy = C₁ · e^x + C₂ · e^(-x) + (1/2) · x · e^x

1Дифференциальные уравнения в полных дифференциалах (вид, признак Эйлера, схема решения)
1. Определение и канонический вид:
Дифференциальным уравнением в полных дифференциалах называется уравнение первого порядка вида:
P(x, y) dx + Q(x, y) dy = 0
левая часть которого представляет собой полный дифференциал некоторой функции двух переменных u(x, y):
du(x, y) = P(x, y) dx + Q(x, y) dy
Тогда исходное уравнение принимает вид: du(x, y) = 0, а его общий интеграл имеет вид:
u(x, y) = C, где C — произвольная постоянная.
2. Необходимое и достаточное условие (теорема Эйлера / признак полного дифференциала):
Пусть функции P(x, y) и Q(x, y) вместе со своими частными производными непрерывны в односвязной области D плоскости xOy.
Выражение P(x, y) dx + Q(x, y) dy является полным дифференциалом некоторой функции u(x, y) тогда и только тогда, когда в каждой точке области D выполняется равенство перекрёстных частных производных (условие Эйлера):
∂P(x, y) / ∂y = ∂Q(x, y) / ∂x
Доказательство (обоснование необходимости):
Если du = (∂u/∂x) dx + (∂u/∂y) dy = P dx + Q dy, то:
P(x, y) = ∂u / ∂x, Q(x, y) = ∂u / ∂y
Дифференцируя P по y, а Q по x и пользуясь равенством смешанных производных второго порядка при условии их непрерывности:
∂P / ∂y = ∂²u / (∂y ∂x) = ∂²u / (∂x ∂y) = ∂Q / ∂x
Следовательно, ∂P / ∂y = ∂Q / ∂x, что и требовалось.
3. Алгоритм и схема нахождения потенциальной функции u(x, y):
1) Проверка условия: вычисляют частные производные ∂P/∂y и ∂Q/∂x. Если ∂P/∂y = ∂Q/∂x, уравнение является уравнением в полных дифференциалах.
2) Интегрирование по x:
Так как ∂u/∂x = P(x, y), интегрируем P(x, y) по переменной x, считая y постоянной величиной:
u(x, y) = ∫ P(x, y) dx + C(y)
где C(y) — неизвестная функция, зависящая только от y (играет роль константы интегрирования по x).
3) Дифференцирование по y:
Дифференцируем полученное выражение для u(x, y) по переменной y:
∂u / ∂y = ∂/∂y [ ∫ P(x, y) dx ] + C'(y)
4) Составление уравнения для C'(y):
Так как по условию ∂u/∂y = Q(x, y), приравниваем производную к функции Q(x, y):
∂/∂y [ ∫ P(x, y) dx ] + C'(y) = Q(x, y)
Отсюда выражаем C'(y):
C'(y) = Q(x, y) - ∂/∂y [ ∫ P(x, y) dx ]
(В силу условия Эйлера переменная x в правой части обязательно взаимно уничтожается, и C'(y) зависит только от y).
5) Нахождение C(y) и запись общего интеграла:
Интегрируем C'(y) по переменной y: C(y) = ∫ C'(y) dy + C₀.
Подставляем C(y) в формулу для u(x, y) и записываем общий интеграл:
u(x, y) = C
2ЛНДУ. Метод вариации произвольных постоянных (метод Лагранжа)
1. Постановка задачи и структура решения:
Рассматривается ЛНДУ n-го порядка:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = f(x)
Для 2-го порядка: y'' + a₁ y' + a₂ y = f(x), где f(x) — произвольная непрерывная функция.
Общее решение ЛНДУ имеет вид: y = ȳ + ỹ, где ȳ — общее решение соответствующего ЛОДУ:
ȳ = C₁ · y₁(x) + C₂ · y₂(x) + ... + Cₙ · yₙ(x)
Метод Лагранжа позволяет найти общее решение неоднородного уравнения при абсолютно любой непрерывной правой части f(x).
2. Вывод системы Лагранжа для уравнения 2-го порядка:
1) Ищем решение ЛНДУ в виде:
y = C₁(x) · y₁(x) + C₂(x) · y₂(x)
где C₁(x) и C₂(x) — неизвестные функции.
2) Находим первую производную: y' = C'₁(x) y₁ + C'₂(x) y₂ + C₁(x) y'₁ + C₂(x) y'₂.
Накладываем дополнительное условие (условие Лагранжа):
C'₁(x) · y₁(x) + C'₂(x) · y₂(x) = 0
Тогда первая производная упрощается: y' = C₁(x) y'₁(x) + C₂(x) y'₂(x).
3) Находим вторую производную:
y'' = C₁(x) y''₁ + C₂(x) y''₂ + C'₁(x) y'₁ + C'₂(x) y'₂.
4) Подставляем y, y', y'' в исходное уравнение. Так как y₁ и y₂ — решения ЛОДУ (y''ᵢ + a₁ y'ᵢ + a₂ yᵢ = 0), все слагаемые с C₁(x) и C₂(x) взаимно уничтожаются, и мы получаем систему уравнений относительно C'₁(x) и C'₂(x):
{ C'₁(x) · y₁(x) + C'₂(x) · y₂(x) = 0
{ C'₁(x) · y'₁(x) + C'₂(x) · y'₂(x) = f(x)
3. Формулы для нахождения функций C₁(x), C₂(x) и общее решение:
Главный определитель системы равен определителю Вронского ФСР: W(x) = y₁ y'₂ - y'₁ y₂ ≠ 0.
По формулам Крамера находим производные неизвестных функций:
C'₁(x) = - [ y₂(x) · f(x) ] / W(x)
C'₂(x) = [ y₁(x) · f(x) ] / W(x)
Интегрируя, получаем:
C₁(x) = - ∫ ( [ y₂(x) · f(x) ] / W(x) ) dx + C̄₁
C₂(x) = ∫ ( [ y₁(x) · f(x) ] / W(x) ) dx + C̄₂
где C̄₁, C̄₂ — числовые произвольные постоянные.
Итоговое общее решение ЛНДУ 2-го порядка:
y = C̄₁ · y₁(x) + C̄₂ · y₂(x) - y₁(x) · ∫ [ (y₂ f(x)) / W(x) ] dx + y₂(x) · ∫ [ (y₁ f(x)) / W(x) ] dx

Решить дифференциальное уравнение: (3x - 5x² y²) dx + (3y² - (10/3) x³ y) dy = 0

P(x, y) = 3x - 5x² y²
Q(x, y) = 3y² - (10/3) x³ y

Билет 8

1Дифференциальные уравнения высших порядков, допускающие понижение порядка
1. Общие принципы понижения порядка:
Понижение порядка дифференциального уравнения — это метод интегрирования, при котором с помощью специальной замены переменной исходное уравнение порядка n сводится к дифференциальному уравнению более низкого порядка (в частности, к уравнению 1-го порядка). Выделяют три основных канонических типа таких уравнений.
2. Основные типы уравнений, допускающих понижение порядка:
ТИП I: Уравнение вида y⁽ⁿ⁾ = f(x)
Уравнение содержит старшую производную и независимую переменную x (в него явно не входят y, y', ..., y⁽ⁿ⁻¹⁾).
Метод решения: n-кратное последовательное интегрирование.
y⁽ⁿ⁻¹⁾ = ∫ f(x) dx + C₁
y⁽ⁿ⁻²⁾ = ∫ [ ∫ f(x) dx + C₁ ] dx + C₂
...
y = φ(x) + C₁ (xⁿ⁻¹ / (n-1)!) + C₂ (xⁿ⁻² / (n-2)!) + ... + Cₙ
ТИП II: Уравнение, не содержащее явно искомой функции y: F(x, y', y'', ..., y⁽ⁿ⁾) = 0
Для уравнения 2-го порядка: F(x, y', y'') = 0
Метод решения:
Вводится замена низшей из присутствующих производных на новую функцию:
y' = p(x) ⇒ y'' = p'(x) = dp / dx
После подстановки получаем уравнение 1-го порядка относительно p(x):
F(x, p, p') = 0
Находим его решение p = φ(x, C₁). Затем возвращаемся к переменной y:
dy / dx = φ(x, C₁) ⇒ y = ∫ φ(x, C₁) dx + C₂
(В общем случае, если низшая производная y⁽ᵏ⁾, замена y⁽ᵏ⁾ = p(x) понижает порядок уравнения сразу на k единиц).
ТИП III: Уравнение, не содержащее явно независимой переменной x: F(y, y', y'', ..., y⁽ⁿ⁾) = 0
Для уравнения 2-го порядка: F(y, y', y'') = 0
Метод решения:
В качестве нового независимого аргумента выбирают переменную y, а производную заменяют функцией p(y):
y' = p(y)
Тогда вторая производная вычисляется по правилу дифференцирования сложной функции:
y'' = d/dx [ y' ] = d/dx [ p(y) ] = (dp / dy) · (dy / dx) = (dp / dy) · p = p · (dp / dy)
После подстановки получаем уравнение 1-го порядка относительно p(y):
F(y, p, p · (dp/dy)) = 0
Интегрируя его, находим p = φ(y, C₁). Затем возвращаемся к x, разделяя переменные:
dy / dx = φ(y, C₁) ⇒ dy / φ(y, C₁) = dx ⇒ ∫ [ dy / φ(y, C₁) ] = x + C₂
2ЛОДУ и ЛНДУ. Связь линейных систем с ЛНДУ высших порядков
1. Сравнительная характеристика ЛОДУ и ЛНДУ:
Линейное однородное ДУ (ЛОДУ) n-го порядка:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = 0
Общее решение ȳ строится через фундаментальную систему решений (ФСР):
ȳ = C₁ y₁ + C₂ y₂ + ... + Cₙ yₙ, где yᵢ — решения, для которых определитель Вронского W(x) ≠ 0.
Линейное неоднородное ДУ (ЛНДУ) n-го порядка:
y⁽ⁿ⁾ + a₁ y⁽ⁿ⁻¹⁾ + ... + aₙ y = f(x), где f(x) ≠ 0
Теорема о структуре общего решения: y = ȳ + ỹ, где ȳ — общее решение ЛОДУ, а ỹ — частное решение ЛНДУ.
Методы нахождения ỹ:
1) Метод неопределённых коэффициентов (метод подбора) — при специальной правой части (квазимногочлен);
2) Метод вариации произвольных постоянных (метод Лагранжа) — при произвольной непрерывной f(x).
2. Сведение систем линейных ДУ к ЛНДУ 2-го порядка (метод исключения неизвестных — из лекций):
Нормальная система двух линейных дифференциальных уравнений с постоянными коэффициентами имеет вид:
{ dx/dt = a₁₁ x + a₁₂ y + f₁(t)
{ dy/dt = a₂₁ x + a₂₂ y + f₂(t)
Метод исключения позволяет свести систему к одному ЛНДУ 2-го порядка:
1) Выражают одну из переменных (например, x) через вторую переменную y и её производную dy/dt из одного уравнения.
2) Дифференцируют полученное соотношение по независимой переменной t, находя d²y/dt².
3) Подставляют выражения для x и dx/dt во второе уравнение системы.
4) Получают линейное неоднородное ДУ 2-го порядка относительно функции y(t):
y'' + p₁ y' + p₂ y = f(t)
5) Находят общее решение y(t) = ȳ(t) + ỹ(t), а затем подставляют его в выражение для x(t), получая полное векторное общее решение системы.

Задача 2 (ДУ 2-го порядка, допускающее понижение порядка — Тип II):
Решить дифференциальное уравнение: x · y'' - y' = x²
1) Определение типа:
Уравнение явно не содержит искомой функции y (Тип II: F(x, y', y'') = 0).
2) Понижение порядка с помощью замены:
Полагаем: y' = p(x) ⇒ y'' = p'(x) = dp / dx
Подставляем в исходное уравнение:
x · p' - p = x²
Делим обе части на x (при x ≠ 0):
p' - (1/x) · p = x — линейное неоднородное ДУ 1-го порядка относительно p(x).
3) Решение уравнения относительно p(x) (методом Бернулли p = u · v):
u'v + u · [ v' - (1/x)v ] = x
• v' - (1/x)v = 0 ⇒ dv / v = dx / x ⇒ ln|v| = ln|x| ⇒ v = x
• u' · x = x ⇒ u' = 1 ⇒ u(x) = x + C₁
Находим p(x):
p(x) = u · v = (x + C₁) · x = x² + C₁ · x
4) Нахождение функции y(x):
Так как p(x) = y' = dy/dx:
dy / dx = x² + C₁ · x
Интегрируем обе части по x:
y = ∫ (x² + C₁ · x) dx = (x³ / 3) + C₁ · (x² / 2) + C₂
Переобозначая произвольную постоянную C₁ / 2 как C̄₁:
y = (1/3) x³ + C̄₁ · x² + C₂
Ответy = (1/3) x³ + C₁ x² + C₂
